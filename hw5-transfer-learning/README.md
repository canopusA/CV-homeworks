# HW5 — Image Classification

Image classification using Transfer Learning with a pretrained YOLO11n-cls model.

## Task

Classify images into three categories:
- Cat
- Dog
- Fox

## Dataset

[Animal Image Dataset — Cats, Dogs, and Foxes (Kaggle)](https://www.kaggle.com/datasets/snmahsa/animal-image-dataset-cats-dogs-and-foxes)

## Method

1. Download and prepare the dataset.
2. Split images into training, validation, and test sets.
3. Load pretrained YOLO11n-cls weights.
4. Fine-tune the model for 10 epochs.
5. Evaluate test accuracy and visualize the confusion matrix.

## Results

The notebook contains the test accuracy and confusion matrix obtained after training.
